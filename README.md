# Игра-мозаика

Адаптивная браузерная игра-пазл: выберите картинку, сложность и соберите мозаику из квадратных фрагментов. Чистый фронтенд (SPA), без бэкенда.

## Возможности

- Галерея изображений с локализованными названиями (RU / EN)
- Автоматический расчёт сеток сложности (5–11 фрагментов по меньшей стороне)
- Управление: клик-клик и перетаскивание через Pointer Events (мышь + touch)
- Адаптивное игровое поле для десктопа и мобильных
- Анимация победы: мигание сетки → показ собранной картинки → сообщение о победе

## Стек

- **React** 18 + **TypeScript** 5
- **Vite** 5
- **Tailwind CSS** 3
- **lucide-react** — иконки

## Происхождение проекта

Исходная версия приложения была сгенерирована в **[bolt.new](https://bolt.new)** по техническому заданию (см. [`prompts/MAIN.md`](prompts/MAIN.md)).

Доработки и исправления выполнены в **Cursor**:

- исправлен пустой экран игры (сетка схлопывалась из-за `w-fit` + CSS Grid `1fr`)
- галерея: миниатюры одинаковой высоты, ширина по пропорциям картинки, `object-contain`
- адаптив галереи на узких экранах (`max-w-full`, масштабирование широких миниатюр)
- анимация победы с миганием и показом целой картинки
- превью и финальная картинка совпадают по размеру с игровым полем

Подробный контекст для разработки: [`.cursor/CONTEXT.md`](.cursor/CONTEXT.md)
